# Plan 04-02: Unified CLI, Pipeline Automation & Profile Switcher

## Goal
Implement the unified command-line interface (`skywatch`), build the end-to-end pipeline orchestrator (`pipeline_runner.py`) executing all stages from raw collection to published REST API export, and formalize the runtime profile switching automation (`use_profile.sh`).

## Context & Requirements
- **OPS-05**: Unified CLI entrypoint `skywatch` supporting `discover`, `collect`, `backfill`, `pipeline`, `export`, and `smoke` (FR-34).
- **OPS-06**: Profile switching script and smoke tests between `modern` and `lab` execution profiles with environment validation (FR-35).
- **OPS-07**: Structured run logging across all pipeline stages with unique run identifiers and defined schema (FR-36).

## Tasks

### Task 1: Unified CLI Interface
<read_first>
- src/skywatch/collector/collector.py
- src/skywatch/pipeline/pig_runner.py
- src/skywatch/pipeline/spark_runner.py
- pyproject.toml
</read_first>

<action>
1. Implement `src/skywatch/cli.py` using `argparse`:
   - Register top-level parser `skywatch` with subcommands:
     - `discover`: Scans Bengaluru bounding box for CAAQMS stations and updates `config/stations.json`.
     - `collect`: Ingests latest air quality and weather telemetry.
     - `backfill`: Performs historical backfill for date ranges.
     - `pipeline`: Runs end-to-end pipeline (ingestion -> Pig ETL -> Spark analytics -> API export).
     - `export`: Generates static JSON lake endpoints from published analytics.
     - `smoke`: Executes end-to-end smoke test suite verifying all stages.
   - Global options: `--profile` (`modern` | `lab`), `--log-level`, `--offline`, `--simulate`.
2. Register console script entrypoint in `pyproject.toml`:
   - `[project.scripts] skywatch = "skywatch.cli:main"`
</action>

### Task 2: End-to-End Pipeline Orchestrator
<read_first>
- src/skywatch/pipeline/pig_runner.py
- src/skywatch/pipeline/spark_runner.py
- src/skywatch/spark/export.py
</read_first>

<action>
1. Implement `src/skywatch/pipeline/pipeline_runner.py`:
   - Coordinates multi-stage batch processing:
     1. Stage 1: Ingestion & Normalization (`IngestionOrchestrator`)
     2. Stage 2: Apache Pig Data Cleansing (`pig_runner.py`)
     3. Stage 3: Apache Spark Analytics & CPCB Indexing (`spark_runner.py`)
     4. Stage 4: Static API Lake Publishing (`export_static_api_endpoints()`)
   - Propagates a unified `run_id` across all stages for quality audit tracking.
   - Emits structured JSON summary with record counts and elapsed runtimes per stage.
</action>

### Task 3: Profile Switcher & Validation Script
<read_first>
- profiles/modern.env
- profiles/lab.env
- src/skywatch/pipeline/profile.py
</read_first>

<action>
1. Enhance `scripts/use_profile.sh`:
   - Supports arguments `modern` or `lab`.
   - Exports environment variables from target `.env` file.
   - Verifies runtime prerequisites:
     - Java version (validates Java 8 for Pig; Java 8 or 17 for Spark).
     - Hadoop and HDFS availability.
     - Spark home and version compatibility (verifying Spark >= 3.2 for Python 3.8 support).
</action>
