# Plan 04-03: Full-Stack Integration Testing, Profile Rollback Drill & Documentation

## Goal
Implement end-to-end full-stack integration tests proving complete data flow from ingestion to frontend schema validation, automate Next.js production build and typecheck verification, execute the dual-profile rollback drill comparing `modern` vs `lab` output parity, and finalize comprehensive project documentation.

## Context & Requirements
- **OPS-06**: Profile switching script and smoke tests between `modern` and `lab` execution profiles with environment validation (FR-35).
- **OPS-07**: Structured run logging across all pipeline stages with unique run identifiers and defined schema (FR-36).
- **Coverage Gate**: Maintain >=80% test coverage floor on core business logic modules.
- **Rollback Parity**: Proves system reproducibility across modern and legacy big data stacks.
