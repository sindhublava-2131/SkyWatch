# Plan 03-01: Core Analytical Engines, CPCB Breakpoints, Freshness Classifier & Spark Session Setup

## Goal
Establish the analytical foundations of SkyWatch: author official CPCB breakpoint tables and piecewise linear sub-index math (`cpcb.py`), implement station freshness classification (`freshness.py`), extend `config/schemas.yaml` for all analytical output entities, and implement the common PySpark session factory (`common.py`) enforcing low-memory configuration (`local[2]`, `spark.sql.shuffle.partitions=2`, `spark.sql.ansi.enabled=false`) and explicit `StructType` mapping without schema inference.

## Context & Requirements
- **SPK-01**: Foundation for station statistics and rankings requiring canonical schema contracts in `config/schemas.yaml` and schema building helpers.
- **SPK-04**: Calculate 24-hour rolling CPCB PM-based National AQI from regularized hourly means using linear interpolation and >=16 valid hours rule, emitting explicit suppression reasons when invalid (FR-23, NFR-02).
- **SPK-06**: Classify station freshness into Fresh (<=3h), Stale (3-24h), and Offline (>24h) (FR-25, NFR-13).
- **Python 3.8 Syntax Floor**: All modules must strictly comply with Python 3.8 (`from __future__ import annotations`, `typing.Optional`, `typing.Dict`, `typing.List`).
- **Low-Memory Spark Ceiling**: Limit driver to 2 GB, fix shuffle partitions to 2 (to prevent 200 default shuffle tasks on local machines), and disable ANSI mode to avoid query aborts on non-fatal malformed casts.

## Threat Model & Mitigations
- **Threat**: JVM Out-of-Memory error on local 4GB RAM machines due to default 200 Spark shuffle partitions.
  - *Mitigation*: Hardcode default `spark.sql.shuffle.partitions=2` in `common.py:get_spark()`.
- **Threat**: Schema drift between Pig clean output and Spark ingestion causing corrupted column mapping.
  - *Mitigation*: Enforce explicit `StructType` constructed from single source of truth `config/schemas.yaml`; disallow `inferSchema=true`.
- **Threat**: Arithmetic division by zero in CPCB interpolation if breakpoints have zero width.
  - *Mitigation*: Breakpoints configuration is statically checked; interpolation logic checks `b_high > b_low`.
