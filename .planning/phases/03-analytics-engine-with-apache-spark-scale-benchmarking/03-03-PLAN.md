# Plan 03-03: Atomic Export Publishing, Synthetic Scale Generator & Benchmarking Suite

## Goal
Implement the atomic dataset export publisher (`export.py`) with atomic staging swaps, dual Parquet/CSV formats, and sidecar `_schema.json` metadata contracts; author the synthetic data generator (`make_synthetic.py`) creating isolated 1× (50k), 10× (500k), and 100× (5M) row datasets; and establish the scale benchmarking runner (`run_scale_benchmark.py`) profiling execution latency, throughput, and memory consumption into `benchmarks/results.md`.

## Context & Requirements
- **SPK-09**: Export dashboard-ready Parquet and CSV datasets to `output/published/` via atomic staging directory swaps (FR-28, NFR-01).
- **SPK-10**: Synthetic scale benchmarking suite testing 1× (50k rows), 10× (500k rows), and 100× (5M rows) volume performance with local and report modes (FR-35, NFR-08).
- **Zero Contamination**: Synthetic data is strictly isolated to `data/synthetic/` and tagged `source="synthetic"` to ensure performance evaluation data never pollutes civic dashboard reports.
- **Atomic Swap Guarantee**: Consumers (Streamlit dashboard) never read partially written files; data is staged in `.staging_{dataset}_{run_id}` and renamed atomically.

## Threat Model & Mitigations
- **Threat**: Synthetic benchmark data accidentally published to user dashboards or production tables.
  - *Mitigation*: Strictly isolate synthetic files to `data/synthetic/` with `source="synthetic"` and `syn_` keys; pipeline runners reject synthetic files unless explicitly running benchmarks.
- **Threat**: Running 100x (5M rows) benchmark exhausting system memory during CI or local testing.
  - *Mitigation*: Benchmark runner provides `--quick` mode (1x only) for ordinary verification; 100x is gated behind `--full` flag; streaming generators write in batches.
- **Threat**: Partial or interrupted writes corrupting published dashboard data.
  - *Mitigation*: Atomic staging directory swap protocol in `export.py` guarantees that consumers only read completely written datasets.
