# Plan 02-01: Canonical Schema Contracts, Sample Fixtures, Apache Pig Scripts & Contract Tests

## Goal
Establish canonical schema contract definitions in `config/schemas.yaml` for clean and aggregated air quality datasets, generate frozen sample datasets and golden reference fixtures, author declarative Apache Pig Latin scripts (`clean_air_quality.pig`, `station_stats.pig`, `hourly_rollup.pig`), and implement contract tests (`test_pig_contracts.py`) verifying schema fidelity across Pig `LOAD ... AS (...)` declarations.

## Context & Requirements
- **PIG-01**: Load normalized air-quality data from HDFS, filter invalid rows, apply safety `DISTINCT`, cast types, write sidecar `_schema.json`, and store headerless clean records (FR-17).
- **PIG-02**: Compute daily station aggregations: reading count, average, minimum, and maximum per pollutant and station (FR-18).
- **PIG-03**: Produce hourly rollups feeding downstream Spark trend analysis and regularized timeseries jobs (FR-19).
- **Canonical Schema Single Source of Truth**: All data contracts stem from `config/schemas.yaml`. Downstream Pig outputs are headerless CSV tuples (`has_header: false`).
- **Python 3.8 Floor**: All test and contract code strictly complies with Python 3.8 syntax.

### Task 2: Declarative Apache Pig Latin Scripts (`clean_air_quality.pig`, `station_stats.pig`, `hourly_rollup.pig`)
<read_first>
- config/schemas.yaml
- .planning/phases/02-big-data-etl-with-apache-pig-hadoop-hdfs/02-RESEARCH.md
- .planning/phases/02-big-data-etl-with-apache-pig-hadoop-hdfs/02-PATTERNS.md
</read_first>

<action>
1. Create `pig/clean_air_quality.pig`:
   - Declare parameters `$INPUT`, `$OUTPUT`, and optional `$RUN_DATE`.
   - Load raw records using `LOAD '$INPUT' USING PigStorage(',') AS (...)` matching canonical `air_quality` schema (14 fields: record_key chararray, station_id chararray, station_name chararray, latitude double, longitude double, sensor_id chararray, parameter chararray, value double, unit chararray, measurement_time_utc chararray, ingestion_time_utc chararray, source chararray, is_valid boolean, reject_reason chararray).
   - Implement data hygiene filter: `FILTER raw_records BY record_key != 'record_key' AND is_valid == true AND value IS NOT NULL AND value >= 0.0 AND value <= 1000.0`.
   - Apply defense-in-depth safety deduplication: `distinct_records = DISTINCT valid_records`.
   - Store headerless output: `STORE distinct_records INTO '$OUTPUT' USING PigStorage(',')`.

2. Create `pig/station_stats.pig`:
   - Declare parameters `$INPUT`, `$OUTPUT`, and optional `$RUN_DATE`.
   - Load clean records using `LOAD '$INPUT' USING PigStorage(',') AS (...)` matching `clean_air_quality` schema.
   - Project date substring using 0-indexed slicing: `SUBSTRING(measurement_time_utc, 0, 10) AS date_dt:chararray` alongside station_id, parameter, and value.
   - Group records by composite key: `GROUP extracted BY (station_id, parameter, date_dt)`.
   - Project aggregations over the bag relation: `group.station_id AS station_id:chararray`, `group.parameter AS parameter:chararray`, `group.date_dt AS date:chararray`, `COUNT(extracted.value) AS reading_count:long`, `ROUND_TO(AVG(extracted.value), 4) AS average_value:double`, `MIN(extracted.value) AS minimum_value:double`, `MAX(extracted.value) AS maximum_value:double`.
   - Store headerless output: `STORE daily_stats INTO '$OUTPUT' USING PigStorage(',')`.

3. Create `pig/hourly_rollup.pig`:
   - Declare parameters `$INPUT`, `$OUTPUT`, and optional `$RUN_DATE`.
   - Load clean records using `LOAD '$INPUT' USING PigStorage(',') AS (...)` matching `clean_air_quality` schema.
   - Regularize hourly buckets using string slicing and UTC suffix concatenation: `CONCAT(SUBSTRING(measurement_time_utc, 0, 13), ':00:00Z') AS bucket_start_utc:chararray` alongside station_id, parameter, and value.
   - Group records by composite key: `GROUP extracted_hours BY (station_id, parameter, bucket_start_utc)`.
   - Project aggregations over the bag relation: `group.station_id AS station_id:chararray`, `group.parameter AS parameter:chararray`, `group.bucket_start_utc AS bucket_start_utc:chararray`, `COUNT(extracted_hours.value) AS reading_count:long`, `ROUND_TO(AVG(extracted_hours.value), 4) AS average_value:double`, `MIN(extracted_hours.value) AS minimum_value:double`, `MAX(extracted_hours.value) AS maximum_value:double`.
   - Store headerless output: `STORE hourly_stats INTO '$OUTPUT' USING PigStorage(',')`.
</action>
