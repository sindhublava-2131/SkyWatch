# Plan 02-02: Python Pig Runner Orchestration, Standalone Fallback & End-to-End Tests

## Goal
Implement the Python Apache Pig runner orchestrator (`pig_runner.py`) with parameter injection, output directory pre-clearing, sidecar schema metadata generation, secure subprocess invocation, and transparent standalone Python simulation fallback; author the shell execution wrapper (`run_pig.sh`); and implement unit and end-to-end integration test suites ensuring sub-90-second ETL execution.

## Context & Requirements
- **PIG-01**: Load normalized air-quality data from HDFS, filter invalid rows, apply safety `DISTINCT`, cast types, write sidecar `_schema.json`, and store headerless clean records (FR-17).
- **PIG-02**: Compute daily station aggregations: reading count, average, minimum, and maximum per pollutant and station (FR-18).
- **PIG-03**: Produce hourly rollups feeding downstream Spark trend analysis and regularized timeseries jobs (FR-19).
- **NFR-04 / Success Criteria 4**: Complete execution of all three ETL scripts on the frozen sample dataset with exit code 0 in under 90 seconds.
- **Python 3.8 Syntax Floor & Subprocess Security**: Enforce `from __future__ import annotations`, structured command token lists without `shell=True`, and path traversal prevention.

<action>
1. Create `src/skywatch/pipeline/pig_runner.py` complying with Python 3.8 syntax floor (`from __future__ import annotations`, standard typing without `|` unions or `match` statements).
2. Define `RunResult` dataclass storing: `script: str`, `returncode: int`, `stdout: str`, `stderr: str`, `duration_seconds: float`, `output_dir: Optional[str] = None`, `records_processed: int = 0`, `success: bool = True`.
3. Implement `is_pig_available(pig_home: Optional[str] = None) -> bool`:
   - Inspect `$PIG_HOME/bin/pig` (or `pig.cmd` on Windows) and `shutil.which("pig")` to detect executable presence.
4. Implement `generate_sidecar_schema(entity_name: str, output_dir: str, config_path: Optional[str] = None) -> str`:
   - Load canonical schema via `skywatch.data.schemas.get_schema`.
   - Write `_schema.json` into `output_dir` specifying `schema_version: "2.0"`, `entity: entity_name`, `format: "csv"`, `delimiter: ","`, `has_header: false`, and canonical column list.
5. Implement `_pre_clear_output(output_dir: str) -> None`:
   - If directory exists, remove it recursively via `shutil.rmtree` to prevent MapReduce `FileAlreadyExistsException`.
6. Implement `_attach_sidecar(script_name: str, output_dir: str) -> None`:
   - Map script to entity (`clean_air_quality.pig` -> `clean_air_quality`, `station_stats.pig` -> `station_stats`, `hourly_rollup.pig` -> `hourly_rollup`) and invoke `generate_sidecar_schema`.
7. Implement `run_pig_script(script_path: str, params: Dict[str, str], profile: Optional[ProfileConfig] = None, mode: str = "local", offline_fallback: bool = True, run_id: Optional[str] = None) -> RunResult`:
   - Wrap in `run_context(run_id)`.
   - Validate script file existence.
   - Inspect `$OUTPUT` parameter, validate against path traversal (`..`), and call `_pre_clear_output`.
   - Check `is_pig_available()`. If unavailable and `offline_fallback=True`, log and delegate to `_run_standalone_fallback`.
   - If Pig is available, construct command argument array `[pig_bin, "-x", mode, "-param", f"{k}={v}", ..., "-f", str(script)]` without `shell=True`.
   - Inject environment variables: `JAVA_HOME=config.java_home_pig`, `PIG_HOME=config.pig_home`, `HADOOP_HOME=config.hadoop_home`.
   - Execute via `subprocess.run(cmd, capture_output=True, text=True, env=env, timeout=90, check=False)`.
   - On exit code 0, invoke `_attach_sidecar` and return `RunResult(success=True)`.
8. Implement `_run_standalone_fallback(script_name: str, params: Dict[str, str]) -> RunResult`:
   - Read all CSV input files from `$INPUT`.
   - For `clean_air_quality.pig`: Strip header, filter records where `is_valid == true`, `value IS NOT NULL`, `0.0 <= value <= 1000.0`, apply deduplication (`set(filtered)`), write headerless tuples to `part-m-00000`.
   - For `station_stats.pig`: Group by `(station_id, parameter, date_dt)` where `date_dt` is timestamp slice `0:10`, compute count, `round(avg, 4)`, min, max, and write headerless tuples to `part-m-00000`.
   - For `hourly_rollup.pig`: Group by `(station_id, parameter, bucket_start_utc)` where `bucket_start_utc` is slice `0:13` + `:00:00Z`, compute count, `round(avg, 4)`, min, max, and write headerless tuples to `part-m-00000`.
9. Add CLI entrypoint `if __name__ == "__main__":` using `argparse` accepting `--script`, `--input`, `--output`, `--run-date`, `--profile`, and `--mode`.
</action>
