# Plan 01-02: Collectors, API Clients, Validation, Normalization & Deduplication

## Goal
Implement robust API clients for OpenAQ v3 and Open-Meteo with rate-limiting backoff, offline mock fixtures, Bengaluru station discovery, data hygiene validation, normalization to canonical schemas, cryptographic SHA-256 deduplication, and untouched raw JSON audit manifest preservation.

## Context & Requirements
- **ING-01**: Collect PM2.5 and PM10 observations from OpenAQ API v3 for Bengaluru monitoring stations (FR-01).
- **ING-02**: Collect hourly temperature, relative humidity, wind speed, and precipitation from Open-Meteo in UTC (FR-02).
- **ING-03**: Auto-discover active Bengaluru stations via `/v3/locations` (bounding box `77.45,12.83,77.75,13.12`) to `config/stations.json` (FR-03).
- **ING-04**: Store unmodified raw API responses with audit metadata (`_manifest.csv`) before any parsing or cleaning (FR-04).
- **HYG-03**: Deduplicate records on composite key `(sensor_id, parameter, measurement_time_utc)` via SHA-256 hash (FR-07).
- **HYG-04**: Validate records for required fields, numeric range, unit sanity (`ug/m3`), and plausible ceilings (PM2.5/PM10 <= 1000 ug/m³), tracking `reject_reason` (FR-08).
- **HYG-05**: Implement exponential backoff, rate limiting (HTTP 429 `Retry-After`), and zero credential leakage (FR-09, FR-10).

### Task 2: Resilient API Clients (`OpenAQClient` & `WeatherClient`)
**Requirements:** ING-01, ING-02, HYG-05  
**Files to create:**
- `src/skywatch/collector/openaq_client.py`
- `src/skywatch/collector/weather_client.py`
- `tests/unit/test_clients.py`

**Steps:**
1. Implement `src/skywatch/collector/openaq_client.py`:
   - Base URL: `https://api.openaq.org/v3`.
   - Initialize with `api_key: Optional[str] = None`, `timeout: int = 20`, `max_retries: int = 5`, `offline: bool = False``.
   - Send `X-API-Key` header if present. Do not log or display key in any exception or log message.
   - Rate limiting and backoff algorithm:
     - On HTTP 429: inspect `Retry-After` header. Sleep `int(retry_after) + random.uniform(0.1, 1.0)`. If header absent, exponential backoff: `min(60.0, 1.5 * (2 ** attempt)) + random.uniform(0.1, 1.0)`.
     - On HTTP 401/403: raise `AuthenticationError` immediately without retry.
     - On 5xx/ConnectionError: exponential backoff up to `max_retries`.
   - Methods:
     - `get_locations(bbox: str, limit: int = 100, page: int = 1) -> Dict[str, Any]`
     - `get_latest(location_id: int) -> Dict[str, Any]`
     - `get_measurements(sensor_id: int, datetime_from: str, datetime_to: str, limit: int = 100, page: int = 1) -> Dict[str, Any]`
     - `get_hours(sensor_id: int, datetime_from: str, datetime_to: str) -> Dict[str, Any]`
   - Offline fallback: If `offline=True` or `OPENAQ_OFFLINE=1`, return mock fixture responses from `tests/fixtures/`.
2. Implement `src/skywatch/collector/weather_client.py`:
   - Forecast endpoint: `https://api.open-meteo.com/v1/forecast`
   - Archive endpoint: `https://archive-api.open-meteo.com/v1/archive`
   - Parameters: `latitude`, `longitude`, `hourly="temperature_2m,relative_humidity_2m,wind_speed_10m,precipitation"`, `timezone="UTC"`.
   - Retry logic with backoff for transient network issues.
   - Offline fallback to `tests/fixtures/sample_weather_*.json`.
3. Create `tests/unit/test_clients.py`:
   - Mock responses with `responses` library.
   - Test 429 response triggers `Retry-After` sleep.
   - Test 401 triggers instant failure.
   - Test offline mode loads fixture files directly.
   - Assert API key is never present in log records or exception representations.

**Verification:**
`pytest tests/unit/test_clients.py`

### Task 4: Data Hygiene Validation Engine
**Requirements:** HYG-04  
**Files to create:**
- `src/skywatch/data/validation.py`
- `tests/unit/test_validation.py`

**Steps:**
1. Implement `src/skywatch/data/validation.py`:
   - Class `ValidationResult`: dataclass with `is_valid: bool`, `reject_reason: Optional[str]`.
   - Validation rules:
     - `check_required_fields(record: Dict[str, Any], required: List[str]) -> ValidationResult`: ensures non-empty values. Failure: `missing_field`.
     - `check_numeric_range(value: Any) -> ValidationResult`: float parsing; checks `value >= 0.0`. Null value -> `null_value`; negative -> `negative_value`.
     - `check_plausible_ceiling(parameter: str, value: float, ceiling: float = 1000.0) -> ValidationResult`: for `pm25` and `pm10`, checks `value <= 1000.0`. Failure: `implausible_spike`.
     - `check_unit(unit: str) -> ValidationResult`: normalizes `µg/m³`, `ug/m^3` to `ug/m3`. If non-concentration unit (e.g. `ppm`, `ppb`), rejects with `invalid_unit`.
     - `check_timestamp(ts_str: str, max_future_seconds: int = 3600) -> ValidationResult`: parses ISO-8601 UTC timestamp. If format invalid -> `invalid_timestamp`. If `timestamp > now_utc + 3600s` -> `future_timestamp`.
   - Composite validator `validate_air_quality_record(record: Dict[str, Any]) -> ValidationResult`: runs the sequential validation chain and stops at first violation or collects reason code.
2. Create `tests/unit/test_validation.py`:
   - Unit tests for each validator function with valid inputs and edge cases (negative values, spikes >1000, nulls, future times, wrong units).

**Verification:**
`pytest tests/unit/test_validation.py`

### Task 5: Feed Normalization Engine
**Requirements:** HYG-01, HYG-02  
**Files to create:**
- `src/skywatch/data/normalization.py`
- `tests/unit/test_normalization.py`

**Steps:**
1. Implement `src/skywatch/data/normalization.py`:
   - `normalize_openaq_record(raw_record: Dict[str, Any], station_meta: Dict[str, Any], ingestion_time_utc: str) -> Dict[str, Any]`:
     - Extracts measurement timestamp from `period.datetimeTo.utc` or `datetime.utc`.
     - Normalizes unit to `ug/m3`.
     - Validates record with `validate_air_quality_record`.
     - Sets `is_valid` and `reject_reason`.
     - Computes `record_key` (via deduplication module).
     - Returns dictionary matching `config/schemas.yaml` air_quality schema.
   - `normalize_weather_response(raw_response: Dict[str, Any], location_id: str, ingestion_time_utc: str, data_kind: str = "forecast_model") -> List[Dict[str, Any]]`:
     - Parses `hourly` parallel arrays (`time`, `temperature_2m`, `relative_humidity_2m`, `wind_speed_10m`, `precipitation`).
     - Normalizes timestamp to ISO 8601 UTC with `:00Z` suffix.
     - Iterates across index $i \in [0, N-1]$ to create row records matching `schemas.yaml` weather schema.
     - Generates `record_key` for weather: SHA-256 hash of `location_id|measurement_time_utc`.
2. Create `tests/unit/test_normalization.py`:
   - Test OpenAQ record normalization matches expected schema fields and types.
   - Test Open-Meteo unrolling creates exact 48 rows for 48 array items with proper timestamps.

**Verification:**
`pytest tests/unit/test_normalization.py`

**Requirements:** HYG-03
